它具体做成了什么样

下面每一条都对应仓库里真实存在的实现，不是设想。

秘钥准入

5 位秘钥，支持逐个输入、整体粘贴、自动跳格。后台能设有效期和使用次数，随时停用。验证通过拿到的令牌只活在页面内存里 —— 一刷新就没了，得重新输。

不进 localStorage

由 AI 先开口

每次进入、每次新建对话，都由模型现生成一句问候，不会重样：服务端记着最近 40 条用过的，生成后还做一次相似度比对（≥ 0.72 判重就重试），实在重复就从 20 句兜底池里挑一句。

快捷提问跟着问候走

问候语下面那排按钮，是照这句问候现场生成的。问候还在路上时，按钮已经先用库里那组摆出来了 —— 不用盯着空白等模型。

流式对话

逐字输出、Markdown 渲染、代码块一键复制；左侧多个历史对话（存在浏览器本地），随时新建或清空。退出登录会连本机保存的对话一起清掉。

后台全可配

AI 名称、开场白方式、接口地址、API Key、模型名称、系统提示词、随机性、最大回复长度、携带历史条数，都在后台改，还能「测试连接」看具体报错。

图标能换

两种做法：默认图标（圆角渐变块 + 最多 4 个字）或自定义图标（上传图片，在圆角框里拖动缩放选位置）。换完全站生效 —— 标签页、徽标、消息头像、分享卡片。

手机上就是能用

窄屏（≤ 820px）侧栏变抽屉，输入框避让 iPhone 底部安全区，输入框字号提到 16px 免得 iOS 聚焦时把整页放大，触屏上删除按钮常驻显示。

Key 不出这台机器

API Key 只存在服务端的 data/db.json，接口调用全部在服务端完成，浏览器拿不到它。走 Cloudflare 隧道时访客真实 IP 取 CF-Connecting-IP，在边缘就挡住了伪造。

只依赖官方接口

任何 OpenAI 兼容的 /chat/completions 都能接：DeepSeek、月之暗面、硅基流动、One-API 中转、OpenAI 官方 —— 换个地址和模型名就换了个「大脑」。

已知取舍与边界

使用前值得知道的事。这些不是缺陷说明，是设计时明确选择的结果。

不做登录失败限流

秘钥输错可以立刻重试，不会被锁、也不会等待 —— 这是有意保留的。代价是公网部署下秘钥能被持续枚举： 请务必用字母数字混合（纯数字只有 10 万种组合），给秘钥设有效期，需要限流就在反向代理层加。

秘钥在库里是明文

后台要把秘钥展示给管理员去分发，所以 db.json 里存的是原文，同样的还有 API Key。 这也意味着 data/ 目录要当敏感文件对待 —— 仓库的 .gitignore 已经把它排除在外了。

电脑关机 = 网站下线

网站跑在你自己的机器上，关机、休眠、断网都会让它不可访问。想要 7×24 就得把它挪到服务器或云主机上。 隧道也没有被装成开机自启的后台服务 —— 要装之前先想清楚。

公网访问要自己配隧道

安装包只让服务监听本机 127.0.0.1，不对局域网敞开。要发布到公网， 用 Cloudflare Tunnel 建一条隧道即可 —— 不需要公网 IP，也不用在路由器上开端口映射，全程 HTTPS。

只面向单机单用户

没有多账号体系、没有云端同步：访客共用一个准入池，对话历史存在各自的浏览器里。 它是「给自己和几个熟人用的站」，不是多租户产品。

没有第三方依赖包袱

运行依赖只有 express 一个，前端没有框架、没有 CDN、没有统计脚本， 连打包用的 zip 写入器都是仓库里自己写的。想审计代码，需要看的量很小。
