# AI 问答网站（秘钥验证版）

一个带准入验证的 AI 对话网站：访客必须输入 5 位秘钥才能进入，秘钥由管理员在后台发放，
可设置有效期与使用次数；AI 名称、接口地址、模型等全部可在后台配置。

---

## 快速开始

```bash
npm install      # 只需装一次
npm start        # 或 node server.js
```

启动后终端会打印访问地址：

| 用途 | 地址 |
| --- | --- |
| 前台（访客） | http://127.0.0.1:3000 |
| 管理后台 | http://127.0.0.1:3000/admin |

**初始管理员密码：`admin123`**（配置在 `config.json` 的 `adminInitialPassword`，首次启动后写入数据库，
之后请在后台「入口与安全」里修改）。

### 首次使用建议按这个顺序配置

1. 打开 `/admin`，用初始密码登录；
2. 到「**AI 设置**」填入接口地址、API Key、模型名称，点「**测试连接**」确认能通；
3. 顺手改掉「**AI 名称**」和欢迎语；
4. 到「**秘钥管理**」生成秘钥，发给使用者；
5. 到「**入口与安全**」修改管理员密码。

## 从公网访问（Cloudflare Tunnel）

网站本身只监听本机的 3000 端口。要让 `https://chat.lumewalk.dpdns.org` 能访问，
用的是 **Cloudflare Tunnel**：不需要公网 IP，也不用在路由器上开端口映射，
由本机的 `cloudflared` 主动连一条加密隧道到 Cloudflare 边缘。

### 平时怎么启动：双击 `启动网站.cmd`

在项目目录里双击 **`启动网站.cmd`** 就行。它用一个窗口当控制台，同时拉起网站本体和隧道，
把两边的日志合在一起显示，起来之后会打印一张状态表：

```
  --------------------------------------------
   [OK] 网站本体   运行中
   [OK] Cloudflare 隧道  已连接
  --------------------------------------------
   公网地址   https://chat.lumewalk.dpdns.org
   本机后台   http://127.0.0.1:3000/admin
   本机前台   http://127.0.0.1:3000
  --------------------------------------------
```

关于这个窗口：

- **关掉它 = 两个一起停**，不会留下孤儿进程；
- 也可以按 `Ctrl+C`，它会先把两个子进程结束掉再退出；
- 它**只杀自己启动的进程**（靠保存的进程号精确定位），不会碰到你其它的 `node.exe`；
- 网站已经在别处跑着时（比如你手动 `npm start` 过），它**不会重复启动**，只负责接隧道，
  退出时也不会去动那个网站；
- 端口 3000 被**别的**程序占着时，它会直接报错退出，不会硬抢。

想分开单独启动、看各自最原始的输出来排错，还有两个备用入口：
项目目录里的 `start.cmd`（只起网站）和 `C:\Users\86136\cloudflared\start-tunnel.cmd`（只起隧道）。
手动启动的话两个窗口都不能关，关掉任意一个网站就下线。

> ⚠️ **改这几个 `.cmd` 时，里面一个中文（非 ASCII 字符）都不能有。**
> Windows 的 cmd.exe 是用**系统 OEM 代码页**（中文系统是 GBK/936）去解析批处理文件的，不是 UTF-8。
> 混进 UTF-8 中文后字节会被错误解码，甚至把后面的换行符一起吞掉、两行粘成一行，
> 结果就是**双击后窗口一闪就退**，还不给你任何像样的报错。
> `chcp 65001` 改的是控制台**输出**编码，管不了脚本**解析**，救不了这个。
> 所以中文提示一律写在 `tools\launcher.mjs` 里（Node 永远按 UTF-8 读文件），`.cmd` 只留纯 ASCII 命令。
> 窗口标题同理，是在 launcher 里用 `process.title` 设的。

### 相关文件

| 路径 | 说明 |
| --- | --- |
| `启动网站.cmd` | 双击启动全部（网站 + 隧道） |
| `tools\launcher.mjs` | 上面那个启动器的本体，改行为改这里 |
| `C:\Users\86136\cloudflared\cloudflared.exe` | 隧道客户端 |
| `C:\Users\86136\cloudflared\start-tunnel.cmd` | 只启动隧道（备用） |
| `C:\Users\86136\.cloudflared\config.yml` | 隧道配置：哪个域名转发到哪个端口 |
| `C:\Users\86136\.cloudflared\<隧道ID>.json` | 隧道凭据，**等同于这台机器的通行证，别外传** |

### 有意没做的事

- **没有把隧道装成开机自启的后台服务**。要装的话是 `cloudflared service install`，
  装完开机就常驻后台 —— 想装之前请先想清楚。
- **电脑关机 / 休眠 / 断网 → 网站下线**。这是「网站跑在自己电脑上」的必然代价；
  想要 7×24 就得把程序挪到服务器或云上。

### 换域名 / 加域名怎么改

1. `cloudflared tunnel create <名字>` 建隧道，记下隧道 ID；
2. `cloudflared tunnel route dns <名字> <域名>` —— 它会**自动**在 Cloudflare 建好 CNAME，
   不需要去面板手动加记录；
3. 在 `config.yml` 的 `ingress` 里加 `- hostname: <域名>` + `service: http://127.0.0.1:3000`，
   **最后一条必须留 `- service: http_status:404` 兜底**，否则 cloudflared 拒绝启动；
4. `cloudflared tunnel ingress validate` 自检，然后 `cloudflared tunnel run <名字>`。

> 隧道后面，「仅本机可访问」以及秘钥记录的真实 IP，都靠 Cloudflare 传来的 `CF-Connecting-IP` 判断
> （直接看 socket 对端只会看到 127.0.0.1）。公网访客伪造这个头也没用：
> Cloudflare 会在边缘直接拒绝，请求根本到不了服务端。

## 功能说明

### 前台
- 进入时弹出 5 位秘钥输入框，支持逐个输入、整体粘贴、自动跳格；
- 进入对话界面后由 AI **主动打招呼**，每次（含每次新建对话）都不同，不会重样；
- 欢迎语下面跟着一排**快捷提问按钮**，内容是照着这句欢迎语现生成的，点一下就发出去；
  - 欢迎语还在路上时，按钮**已经先摆出来了**（用库里的那组），不用干等着模型；
- 验证通过后进入类 ChatGPT 的对话界面：流式逐字输出、Markdown 渲染、代码块一键复制；
- 左侧可管理多个历史对话（保存在浏览器本地），可随时开新对话 / 清空；
- 侧边栏底部是**退出登录**按钮（红底红字，好找），点它会退出登录**并清掉本机保存的对话记录**；
- **已适配手机端**：窄屏下侧栏自动收起为抽屉，输入区固定底部并避让刘海 / 小白条，
  触屏上删除按钮常驻可见，详见下方「移动端适配」。

### 后台
- **概览**：秘钥总数、有效 / 过期 / 停用数量、累计使用、当前在线、运行信息。
- **AI 设置**：AI 名称、开场白方式、欢迎语、**网站图标**、接口地址、API Key、模型名称、系统提示词、
  随机性 temperature、最大回复长度、携带历史条数，并可「测试连接」。
  - 网站图标两种做法：**默认图标**（圆角渐变块 + 自定义文字，最多 4 字）或
    **自定义图标**（上传图片，在圆角方框里拖动、缩放选位置）。详见下方「网站图标」。
  - 开场白方式三选一：**AI 学习库** / **AI 实时生成** / **固定欢迎语**；
  - 「AI 实时生成」：每次进入或新建对话都由模型现场生成一句问候，
    服务端会记录最近 40 条已用过的问候语并在提示里要求避开，生成后还会做一次相似度比对
    （去标点后比较，相似度 ≥ 0.72 判定为重样），最多重试 3 次；
    若接口未配置或多次生成仍重复，则从内置的 20 句兜底池里挑一句没怎么用过的，保证界面永远不会空着；
  - 「固定欢迎语」：每次都使用上面填写的欢迎语；
  - 「AI 学习库」：从下面选中的那个库里取，见下方「欢迎语库（AI 学习）」。

### 欢迎语库（AI 学习，可以建多个）

把「让 AI 写作」从**用户每次进入时**提前到**后台空闲时**，前台进入就不必再等模型。

**多个库，各管一个场景**

- 后台可以建任意多个库，每个库有自己的名称和一句**主题说明**（写给 AI 看的场景提示）；
- 「**当前使用的库**」就是前台取欢迎语的那个库。切库的同时会**自动把「开场白方式」也切到「AI 学习库」**——
  选了库就是要用它，否则在「AI 实时生成 / 固定欢迎语」模式下前台根本不读库，切换会看起来毫无反应；
- 内置两个：

  | 库 | 主题说明 | 预置内容 |
  | --- | --- | --- |
  | 默认欢迎语库 | 通用场景，什么话题都可以聊 | 空库 + 4 条通用兜底提问 |
  | 雨花台烈士陵园 | 参观者咨询雨花台烈士陵园的相关问题 | 6 句欢迎语 + 4 条参观类提问 |

  雨花台库预置的全是**问题**（「有哪些主要纪念建筑？」这类），不含任何史实陈述，不会编造内容；
  想让 AI 讲得更准，把相关资料放进「系统提示词」，或直接问它并核对官方来源。

- **一键学习**：点「立即学习」，AI 会结合当前 AI 名称和**这个库的主题说明**生成一批新的开场白，
  逐条去重（同一套相似度判定）后存进**当前这个库**；
- **每天自动学习**：打开开关并选好运行时刻，到点会**给每个库各学一批**（一个库一次模型调用），
  同时淘汰用腻的旧句子，**不需要人工干预**。定时器每分钟醒一次判断是否到点，进程重启也不会漏掉——
  如果关机期间错过了运行时刻，下次启动 15 秒后会补上；
- **容量与淘汰**：可设**每个库**的容量上限（默认 60 条）。超出时优先淘汰**已经被用得最多**的句子
  （说明前台早就见腻了），并列时保留较新的，让库一直保持新鲜；
- **前台取用**：进入页面时从当前库里挑一句，优先级是「没出现过的 → 用得最少的 → 最久没用的」，
  再从前 3 名里随机取，避免顺序固定。库里每句都记了使用次数和最后使用时间；
- **完全可编辑**：库名、主题说明、库里的句子和提问都能改；句子点一下就地改、逐条删、手动添加、一键清空；
  每次学习都会在「运行日志」里记下**是哪个库**、新增 / 淘汰了几条，成功失败一目了然；
- **当前在用哪个库，一眼可见**：库选择器下面有一行状态——
  前台确实在用某个库时显示绿色「前台正在使用「某某库」的欢迎语」；
  用的是「AI 实时生成」或「固定欢迎语」（即没在读库）时显示橙色提醒，
  并附一个「**让前台用它**」按钮，点一下就切到当前选中的库，不用再回头去上面改「开场白方式」；
- 库还是空的时候，前台会自动退回「AI 实时生成」，不会出现空白头像和空消息；
- 接口没配置好时，自动学习会**静静等待**而不推进运行记录，等你在后台填好接口，下个整点就会自己补上。

> 开「自动学习」会持续消耗 token（每个库每次 6 句左右，很便宜但不是零）。
> 库越多花得越多，不想让它常驻跑可以关掉开关，改用手动「立即学习」。

### 快捷提问按钮

进页面时欢迎语下面那排按钮，是**跟着当句欢迎语实时生成**的——欢迎语说「雨花台」，它就问雨花台的事。

- 每个库都有一组「**兜底快捷提问**」（在同一个卡片里编辑）。前台进入时**先秒出这一组**，
  紧接着后台按当句欢迎语生成更贴合的，回来后就地替换掉，所以用户不会干等；
- 生成失败、超时、或接口没配好时，就一直用兜底那组，界面上没有任何报错；
- 模型返回的必须**本来就是问句**（有问号，或含「哪些 / 怎么 / 是否」这类疑问词）才会被采用，
  免得给陈述句硬补个问号造出莫名其妙的问题；合格的不够 2 条就整组退回兜底；
- 只有「还是那个对话、还停在开场白这一屏」时才会替换，用户已经聊起来了就不会再往里插按钮。

> 代价：每次进页面多一次模型调用（多花几百 token、大约 1~3 秒）。
> 想省掉这一步，把库里的兜底提问编好即可——生成只是让提问更贴题，不是必须的。

### 网站图标

在后台「AI 设置 → 网站图标」里改。改了之后**四个地方同时变**：

| 用在哪 | 怎么生效 |
| --- | --- |
| 浏览器标签页 | `/api/icon`，页面 `<link rel="icon">` 上带版本号 |
| 前台对话界面 | 进入页的大徽标、侧边栏小徽标、AI 消息头像 |
| 后台管理界面 | 登录页和侧边栏的徽标 |
| 微信 / QQ 分享卡片 | `og:image`，是**绝对地址的 PNG**（这两个都不认 SVG） |

两种做法，二选一：

- **默认图标**：固定的斜向渐变圆角块 + 文字，文字最多 4 个字，留空则取 AI 名称前两字。
  右边有实时预览，改字即时变。
- **自定义图标**：上传一张图（PNG / JPG / WebP），在圆角方框里**按住拖动**、用滑块或滚轮**缩放**，
  摆好位置再保存——和 QQ 换头像一个手感，只是裁出来的是圆角正方形。导出 512×512，
  四个角是透明的（不是白色），所以放在任何底色上都自然。

几个实现上的取舍，说明一下为什么这么做：

- **服务端只存一张 512×512 的 PNG**（`data/icon.png`），四种用途全部指向同一个地址。
  这样不用维护两套渲染，也天然满足微信/QQ 只要位图不要 SVG 的要求。
- **画图在浏览器里做**，服务端不依赖任何图形库（本站只有 express 一个依赖）。
- **换图标会让 `iconVersion` 加一**，页面上的地址变成 `/api/icon?v=N`。
  Safari 和微信对 favicon 的缓存极其顽固，靠版本号才能真正换掉。
- 「恢复默认图标」会删掉你上传的那张，并按当前设置重新画一版默认图。

> 出厂的默认图是仓库里的 `public/assets/icon-default.png`（不带文字以外的花样的那张「AI」）。
> 它由 `node tools/make-default-icon.mjs` 生成，脚本里手写了 PNG 编码和字形几何，
> 不依赖任何图形库。想换出厂样式就改脚本里的常量再跑一次。
- **秘钥管理**：
  - 批量生成（可选字母数字混合 / 纯数字）或自定义 5 位秘钥；
  - 每条可设**有效期**（长期有效 / 按分钟·小时·天 / 指定到期时间 / **一次性**）和**可登录次数**；
  - **一次性**：这个秘钥只能被用来登录一次，用过就作废，适合发给只借用一次的人。
    它和「可登录次数填 1」是同一件事（底层就是 `maxUses = 1`），只是换了个更直观的入口，
    列表里也会显示成「有效期：一次性」、用掉后状态变成「已使用」；
    已经登录的那个人**不会被踢下线**，会话照常有效到过期为止——一次性限制的是「登录」，不是「用多久」；
  - 支持停用、启用、续期、删除、批量删除、点击复制。
- **入口与安全**：
  - 前台：可关闭「需要秘钥进入」，关闭后出现「仅本机可访问」开关；
  - 后台：可关闭「后台需要密码」，关闭后同样出现「仅本机可访问」开关；
  - 修改管理员密码（改完后所有后台会话强制下线）。
- **预览效果**：在后台直接查看前台页面在**手机 / 平板 / 电脑**上的真实显示效果。
  - 一键切换 375 / 414 / 768 / 1024 / 桌面自适应五种宽度，可横竖屏互换、随时刷新；
  - 预览框内的**视口就是设备的真实尺寸**（375 就是 375×812，媒体查询和 `vh` 单位都按真机算），
    只是整机等比缩小到能一眼看全，右上角会标出当前缩放比（如 `375 × 812 · 86%`）；
  - 预览用的是你当前的管理员身份，**不需要输入秘钥**，页面左上角会显示「预览模式」标记；
  - 未登录的访客打开前台，看到的仍然是秘钥验证页。

## 秘钥规则

- 长度固定 **5 位**。
- 字符集：
  - 字母 + 数字：`ABCDEFGHJKLMNPQRSTUVWXYZ23456789`（32 个字符，约 **3355 万**种组合）；
  - 纯数字：**10 万**种组合，仅适合内部测试，公网使用建议用字母数字混合。
- 为避免看错，**不使用字母 I、O 和数字 0、1**；自定义秘钥时同样受此限制。
- 秘钥在数据库中**明文保存**（后台需要展示给管理员分发），因此请勿用短数字秘钥暴露在公网。
- **本站不限制登录失败次数**，输错可以立即重试，不会被封锁。代价是秘钥可被持续枚举，
  公网部署请务必使用字母数字混合字符集并设置有效期，必要时在反向代理层加限流。

任何 **OpenAI 兼容**的 `/chat/completions` 接口都可以，例如：

| 服务 | 接口地址（Base URL） | 模型名称示例 |
| --- | --- | --- |

接口地址填到 `/v1` 为止即可，也可以直接填完整的 `.../chat/completions` 地址。

## 移动端适配

前台和后台都做了响应式处理，手机上打开即是可用状态，无需单独做 App。

**前台**
- 视口宽度 ≤ 820px 时，左侧历史对话栏变为**抽屉**，点左上角按钮滑出，带半透明遮罩；
- 高度用 `100dvh`，手机上地址栏收缩 / 展开不会把输入框顶出屏幕；
- 输入框加 `env(safe-area-inset-bottom)` 内边距，避开 iPhone 底部的小白条，
  顶部同样避开刘海；页面禁止橡皮筋回弹（`overscroll-behavior: none`）；
- 所有输入框字号提到 **16px**，避免 iOS 在聚焦时自动放大整个页面；
- 触屏设备（`hover: none`）上，历史对话的删除按钮**常驻显示**（桌面端仍是悬停显示），
  并把可点区域放大到适合手指的尺寸；
- 另针对超窄屏（≤ 380px）和横屏矮窗口（高度 ≤ 520px）做了收紧。

**后台**
- 视口宽度 ≤ 860px 时，左侧导航变成**顶部横向可滑动的标签条**，主区域单列铺满；
- 表单的两列 / 三列栅格自动并成单列，表格可横向滑动；
- 「预览效果」里的设备框会随后台窗口高度自动调整，保证在小屏后台里也能完整看到。

> 想确认效果，不必真拿手机去试：后台「**预览效果**」标签页可以直接切到 375 / 414 宽度查看。

## 动画与动态效果

全站动画集中在一个文件 `public/assets/motion.css`，前台后台共用同一套运动语言（时长、缓动、
逐条入场的错峰间隔都由文件顶部的 CSS 变量统一控制）。它在这两页的 `style.css` / `admin.css`
**之后**引入，只覆写不重复定义 —— 想整体关掉动画，摘掉那一个 `<link>` 就行。

**两条硬规矩**

- **只动 `transform` 和 `opacity`。** 这既是性能要求（留在合成层，不触发重排），也是功能要求：
  聊天区的自动滚动靠 `scrollHeight` 判断，动画一旦改高度或外边距，滚动位置就会抖。
- **入场动画是按需挂类的，不是默认开着。** 消息、历史条目、表格行这些会整块重绘的地方，只有
  真正新出现的节点才挂上 `.msg-enter` / `.hist-enter` / `.row-enter` 这类类名（前台用 `WeakSet`
  记录对象身份，后台用 id 集合比对）。否则每重绘一次，整屏动画就跟着重播一次。

**动态背景**

页面上那层缓慢漂移的光晕是 `body::before`（两团大色块，26s 循环），细网格质感来自静态的
`body::after`。纯 CSS 合成层动画，没有 JS 参与。窄屏（≤ 700px）会关掉网格层，并把漂移放慢到 42s。

**减少动态**

跟随系统的「减少动态效果」：开启后浏览器会给出 `prefers-reduced-motion: reduce`，`motion.css`
末尾会把动画一次性全部关掉（`animation: none !important`），过渡压到 0.01ms。关掉的是动画本身，
不是把元素停在动画开头，所以内容一定还看得见。后台统计卡的数字滚动是 JS 补间，单独做了同样的判断。

> 为什么用一票 `animation: none` 而不是把时长压成 0.01ms：带 `both` / `forwards` 填充的动画
> 即使只剩 0.01ms 也仍然算「在播」，会一直挂在 `getAnimations()` 里空转。

## 安全提示

1. **务必修改默认管理员密码**，`admin123` 只是初始值。
2. API Key 只存在服务器本地 `data/db.json`，**不会下发到浏览器**；接口调用全部在服务端完成。
3. 秘钥位数只有 5 位，属于「方便分发」与「安全性」的折中；且本站**不做失败限流**，
   意味着可以无限次试错。若部署在公网，建议：
   - 使用字母数字混合字符集（避免纯数字，10 万种组合可被快速穷举）；
   - 给秘钥设置合理的有效期；
   - 配合反向代理做 IP 白名单或额外限流。
4. 走 Cloudflare Tunnel 时**全程 HTTPS**：浏览器 ↔ Cloudflare 加密，Cloudflare ↔ 本机走隧道也是加密的，
   不需要自己配证书。若改用 Nginx / Caddy 反代，请自行套 HTTPS。
5. `data/db.json` 含全部秘钥和 API Key，注意备份与权限，不要提交到代码仓库。

## 常见问题

**Q：提示「无法连接 AI 接口」？**
A：到后台「AI 设置」检查接口地址、API Key、模型名称，点「测试连接」看具体报错。
`401` 多为 Key 无效，`404` 多为地址或模型名写错，`429` 多为额度不足或频率超限。

**Q：局域网其他电脑打不开？**
A：确认 `config.json` 里 `host` 是 `0.0.0.0`，并放行 Windows 防火墙的 3000 端口。

**Q：公网域名打不开？**
A：先看 `启动网站.cmd` 那个窗口是不是还开着、状态表里两行是不是都 `[OK]`。
如果窗口不小心被关了，重新双击 `启动网站.cmd` 即可。
两行都 OK 还是打不开，运行 `cloudflared tunnel info ai-website` 看隧道状态。
注意：网站在你自己电脑上，关机 / 休眠 / 断网它就下线了。

**Q：开了「仅本机可访问」之后，我自己也进不去后台了？**
A：这是**正确行为，不是故障**。这个开关的意思就是「只认本机」，你从公网域名访问会被判为外来访客。
改用 `http://127.0.0.1:3000/admin` 即可。程序在隧道后面时会读 Cloudflare 传过来的
`CF-Connecting-IP` 判断真实访客来源，所以公网访客伪造这个头也没用。

**Q：为什么 AI 想了半天才出答案？有时候干脆只有「思考」没有回答？**
A：你用的是**推理模型**（如 `deepseek-v4-flash`），它会先输出一大段思考过程，再给正式回答，
所以等待时间天然比普通模型长。如果后台「AI 设置 → 最大回复长度」设得太小（比如 2048），
思考就把额度用光了，**正式回答会是空的**，日志里该次请求的结束原因是 `length`（被截断）。
把它调到 **16384** 以上即可 —— `max_tokens` 是**上限不是目标**，调高本身不会多花钱，
只在模型真的需要时才多生成。想更快更省，可以考虑换成非推理模型。

**Q：忘记管理员密码了？**
A：关闭服务，编辑 `data/db.json`，把 `settings.adminPasswordHash` 改成空字符串 `""`，
重启后会用 `config.json` 里的 `adminInitialPassword` 重新初始化。

**Q：怎么让某些人不用秘钥就能用？**
A：在「入口与安全」里关闭「需要秘钥才能进入」即可，但此时建议同时打开「仅本机可访问」。

**Q：欢迎语库会一直变大吗？学习是不是很贵？**
A：不会。**每个库**都有容量上限（默认 60 条），超出就淘汰用得最多的；每个库每次学习默认只生成 6 句，
按主流模型的价格算很便宜，不想常驻可以关掉「每天自动学习」改用手动「立即学习」。
注意「每天自动学习」是**所有库都学**，库越多，每天花的 token 越多。

**Q：怎么让网站只聊雨花台烈士陵园？**
A：到「AI 设置 → 欢迎语库」，把「当前使用的库」切成「雨花台烈士陵园」就行——
这一下会**自动把「开场白方式」也切到「AI 学习库」**，欢迎语和下面的快捷提问立刻都变成雨花台的。
如果想改回去，选回「默认欢迎语库」，或者把「开场白方式」改回「AI 实时生成」。
想让回答也严谨，把参观资料整理进「系统提示词」，并提醒使用者核对官方来源。

**Q：下面那排快捷提问按钮是固定的吗？**
A：不是，是照着**当句欢迎语**现生成的，所以欢迎语换话题、按钮也跟着换。
生成要花一次模型调用（约 1~3 秒），页面会先显示每个库的「兜底快捷提问」顶上，
生成好了再无声替换；生成失败就用兜底那组，不会报错也不会空着。

**Q：换了网站图标，但浏览器标签页上还是旧的？**
A：Safari 和微信对 favicon 的缓存极其顽固，普通刷新甚至强刷都可能不动。程序已经做了两件事来对付它：
页面里的图标地址会跟着 `iconVersion` 变成 `/api/icon?v=3` 这样，而且对得上的版本给的是
一年强缓存、对不上的走 `no-cache` 重新校验。所以正常情况下**保存后刷新一下就变了**；
真遇上不动的，把标签页关掉重开，或者换个浏览器确认服务端确实已经换了
（直接打开 `http://127.0.0.1:3000/api/icon` 看那张图是不是新的）。

**Q：自定义图标裁出来的四个角为什么是透明的？**
A：故意的。圆角方块外面的像素留成透明而不是填白，放在浅色底、深色底、深色模式的侧边栏上都自然；
要是填白，深色模式下就会看到四个白角。后台里那两个预览画布底下铺了棋盘格，就是为了让你看清哪部分是透明的。

**Q：自动学习到点了怎么没动静？**
A：先看「运行日志」有没有记录。若显示「尚未配置 AI 接口」，说明 Base URL / API Key / 模型
还没填全——这时服务会一直等着，**不写日志也不推进运行记录**，等你填好后下个整点就会自己补上。
另外运行时刻用的是**服务器本地时间**。

**Q：手机上打开，左边那栏去哪了？**
A：窄屏下侧栏收成了抽屉，点左上角的 ☰ 按钮滑出，点右侧空白处收起。

**Q：后台「预览效果」里为什么不用输秘钥就能进前台？**
A：因为预览用的是你当前的管理员登录身份，这样调样式时不用来回输秘钥；
页面左上角有「预览模式」标记。它只对**已登录的后台会话**生效，
把预览窗里的链接发给别人（或换一个浏览器打开），看到的仍是秘钥验证页。
